# Tahmid Sarker

Personal portfolio (Next.js + TypeScript static export).

**Live:** https://tahmid-sarker.github.io/

## Local

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — local development
- `npm run build` — static export to `out/`
- `npm run clean` — remove `.next` and `out`
- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript (`tsc --noEmit`)
